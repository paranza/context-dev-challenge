# The Web Is Your Real-Time Database

This repository is for a solo submission to Context.dev's secondary main challenge at Junction 2026: European Tech Renaissance.

## Challenge

Build a product that reacts to the live web. The product should turn current web data into useful decisions, actions, or experiences, and ideally respond as that data changes over time.

The challenge brief, judging criteria, and Context.dev resources are recorded in [the challenge notes](docs/challenge.md). Project direction and next steps are in [the working brief](docs/working-brief.md).

## Current stage

Challenge context is captured. Company-specific material, focused research, and the idea from the earlier brainstorming session will be added in that order. No product concept or technical stack has been selected yet.
